# Approved candidate-authority index

This directory is reserved for the versioned offline index generated by:

```powershell
uv run python -m app.candidate_index_cli `
  --calibration data/research_catalog/v1/candidate_calibration.json
```

The builder creates `v1/manifest.json`, `v1/chunks.json`, and `v1/index.npz`
only after the catalogue contains exactly 25 officially sourced authorities
with approved Case Maps and the calibration file contains at least 20 legally
reviewed queries.

The current catalogue is awaiting legal review, so no runtime index is checked
in yet. The API must report candidate search as unavailable rather than reading
the 78-case queue or producing substitute authorities.

Each calibration query contains `question`, `facts`, `claim_text`,
`proposition`, and an `expected_citations` array. The file itself records
`review_status: approved`, `reviewer`, and `reviewed_at`.
